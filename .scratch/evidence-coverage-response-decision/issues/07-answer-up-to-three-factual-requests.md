# 07 — 支持最多三项事实诉求的部分有据回答

**What to build:** 一条复合消息中的最多三项事实诉求分别检索和判断，再按访客原始顺序组合成有据回答、部分有据回答或其他对应结果，使已知部分可以安全回答而未知部分保持明确。

**Blocked by:** 04 — 用证据覆盖决定单项回答或可靠拒答; 05 — 提供两轮澄清与人工接续; 06 — 识别并呈现知识冲突.

**Status:** ready-for-agent

- [ ] 最多三项完整事实诉求分别执行召回、重排和证据覆盖判定，跨诉求重复候选可以去重但不能混淆证据关系。
- [ ] 三项全部受到支持时形成有据回答；至少一项支持且另有无支持、冲突、待澄清或人工接续时形成部分有据回答。
- [ ] 响应按访客原始诉求顺序流式呈现，每个段落拥有独立状态和服务端引用。
- [ ] 无支持段落不显示支持性引用，冲突段落显示冲突双方引用，待澄清和人工接续段落使用受控表达。
- [ ] 每个无支持或冲突事实诉求分别创建待解决问题，不把整条复合消息重复记录为可靠拒答。
- [ ] 部分有据回答显示“以上已回答部分有帮助吗？”并接受一次整体反馈；负面反馈额外记录回答质量问题，不覆盖已有诉求级知识缺口。
- [ ] 超过三项事实诉求时请求访客缩小范围，并计入两轮澄清上限。
- [ ] 公开助手、管理员预览、持久化、会话复盘、反馈和待解决问题通过同一完整场景验证。
