# 08 — 在会话复盘中展示结构化决策审计

**What to build:** 管理员可以从会话复盘中理解每项事实诉求为何被回答、未覆盖、判为冲突或转入人工接续，并据此维护知识来源和处理待解决问题。

**Blocked by:** 07 — 支持最多三项事实诉求的部分有据回答.

**Status:** ready-for-agent

- [ ] 会话列表、筛选和结果标签能够区分有据回答、部分有据回答、知识冲突、可靠拒答、澄清提问、人工接续、交流性回应和技术故障。
- [ ] 会话详情按原始顺序展示事实诉求、完整性、最终状态和逐项引用。
- [ ] 管理员可以查看实际采用的最小证据片段、支持或冲突关系、简短判定说明及请求分析和覆盖策略版本。
- [ ] 一条部分有据回答可以展示并跳转到多个关联待解决问题，且能区分知识缺口、知识冲突和负面质量反馈。
- [ ] 知识来源更新或删除后，复盘仍显示判定时保存的最小证据快照和来源身份。
- [ ] 审计界面不展示模型隐藏推理、原始系统提示词、完整内容单元或无关会话内容。
- [ ] 新审计信息遵守组织边界、会话删除和保留策略，并通过管理员浏览器场景验证。
