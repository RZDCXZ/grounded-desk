# 04 — 用证据覆盖决定单项回答或可靠拒答

**What to build:** 单项完整事实诉求在召回和重排后接受独立的证据覆盖判定，只有没有任何可验证支持时才可靠拒答，使相关性分数不再直接等同于证据充分性。

**Blocked by:** 03 — 用请求分析器替代固定路由规则.

**Status:** resolved

- [ ] 单项事实诉求的候选内容单元由重排排序和降噪，但统一重排阈值不再拥有直接触发可靠拒答的一票否决权。
- [ ] 覆盖判定器只能返回支持、无支持或冲突状态，并为支持结论提供候选内容单元身份、连续原文片段和简短理由。
- [ ] 服务端验证内容单元的组织与候选归属，并验证原文片段确实存在；无效判定重试一次后形成技术故障。
- [ ] 受到支持的事实诉求只使用验证后的证据片段生成有据回答，并获得对应的服务端引用与证据快照。
- [ ] 完整事实诉求全部无支持时形成可靠拒答、提供人工联系入口并创建待解决问题。
- [ ] 覆盖判定、召回或回答供应商失败不得保存成可靠拒答，也不得创建知识缺口。
- [ ] 回归样例证明低于旧硬阈值但证据充分的问题可以回答，而主题相关但不能支持结论的内容不会被误用。
- [ ] 安全测试覆盖伪造内容单元身份、近似引文、提示词注入、来源外事实和错误引用。
