# 02 — 迁移现有单项回答到分段契约

**What to build:** 让现有单项有据回答、可靠拒答、交流性回应和澄清提问通过新的分段流式与完成契约运行，同时保持访客、管理员预览和会话复盘中的可观察行为不变。

**Blocked by:** 01 — 扩展逐项回答数据契约.

**Status:** resolved

- [ ] 单项有据回答通过一个有稳定顺序和身份的响应段流式返回，并在完成时保存对应事实诉求与引用。
- [ ] 可靠拒答、交流性回应和澄清提问可以通过相同完成契约持久化，且不获得不允许的引用或反馈。
- [ ] 公开助手和管理员预览能够消费分段事件，正文、引用、人工联系入口和故障展示与迁移前一致。
- [ ] 管理员会话列表与详情可以读取新契约产生的既有结果，不改变现有标签和统计语义。
- [ ] 迁移不增加新的 AI 调用，也不改变当前路由、检索、阈值或澄清行为。
- [ ] 服务与浏览器回归测试证明公开回答、预览、持久化、引用、反馈、待解决问题和技术故障继续成立。
