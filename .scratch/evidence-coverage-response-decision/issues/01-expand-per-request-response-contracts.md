# 01 — 扩展逐项回答数据契约

**What to build:** 在不改变现有访客体验的前提下，为一条助手消息关联多项事实诉求、逐项引用、证据快照和多个待解决问题建立向后兼容的数据契约，使后续功能可以逐步接入而不破坏既有结果。

**Blocked by:** None — can start immediately.

**Status:** resolved

- [ ] 现有有据回答、可靠拒答、交流性回应、澄清提问和技术故障数据继续满足原有约束并可正常读取。
- [ ] 新契约可以保存一条消息中最多三项有顺序的事实诉求，并记录完整性、覆盖状态、澄清轮次和策略版本。
- [ ] 新契约可以把引用和最小证据快照关联到具体事实诉求，同时保留历史消息级引用的读取能力。
- [ ] 证据快照保存来源身份、支持或冲突关系、受限原文片段和判定说明，并继承组织隔离、会话保留与删除语义。
- [ ] 新增部分有据回答、知识冲突和人工接续结果类型，但在功能接入前不改变现有公开行为。
- [ ] 同一助手消息可以关联多个诉求级待解决问题，并允许消息级负面质量反馈与诉求级知识缺口并存且不重复建项。
- [ ] 数据库契约测试覆盖组织边界、结果类型、逐项引用、证据快照、反馈、待解决问题和级联删除。
