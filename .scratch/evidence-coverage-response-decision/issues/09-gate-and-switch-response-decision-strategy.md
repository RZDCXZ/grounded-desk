# 09 — 建立决策发布门槛并切换新策略

**What to build:** 使用版本化决策评测集证明新策略能够降低错误拒答且不增加来源外事实，通过门槛后让公开助手与管理员预览统一使用新策略，并收回旧的关键词与硬阈值决策路径。

**Blocked by:** 03 — 用请求分析器替代固定路由规则; 04 — 用证据覆盖决定单项回答或可靠拒答; 05 — 提供两轮澄清与人工接续; 06 — 识别并呈现知识冲突; 07 — 支持最多三项事实诉求的部分有据回答; 08 — 在会话复盘中展示结构化决策审计.

**Status:** ready-for-agent

- [ ] 版本化决策评测集覆盖单项与复合诉求、全部与部分覆盖、知识冲突、两轮澄清、人工接续、交流混合业务问题、中英文、安全输入和供应商故障。
- [ ] 每个样例标注预期事实诉求、完整性、证据覆盖、消息级结果、引用、待解决问题和语言。
- [ ] 评测报告错误拆分、错误回答、错误拒答、部分回答错误、冲突漏检与误报、不必要澄清、错误人工接续、来源外事实、错误引用、调用量和延迟。
- [ ] 契约评测中来源外事实、不可验证证据片段、错误引用和技术故障伪装成可靠拒答均为零。
- [ ] 新策略的错误回答不高于旧基线，并实质降低错误拒答；现有检索基线继续作为召回与引用回归测试。
- [ ] 公开助手和管理员预览在同一次发布中切换到同一策略版本，预算、频率、会话上限和技术故障行为通过回归。
- [ ] 删除固定表达集合、范围外正则、残缺主题白名单和统一重排阈值直接触发拒答的旧路径，不以恢复这些规则作为回滚方式。
- [ ] 历史会话、引用、反馈和待解决问题不重新分类或回填，新策略版本与发布验证结果可供管理员审计。
