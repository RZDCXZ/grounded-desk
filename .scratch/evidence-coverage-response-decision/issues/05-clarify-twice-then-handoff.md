# 05 — 提供两轮澄清与人工接续

**What to build:** 信息不完整的事实诉求可以获得最多两轮有针对性的澄清；仍无法形成完整诉求时，助手通过人工接续结束自动处理，而不是把访客信息不足误记成知识不足。

**Blocked by:** 03 — 用请求分析器替代固定路由规则.

**Status:** ready-for-agent

- [ ] 请求分析器为不完整事实诉求返回具体缺失信息，访客看到针对该缺失信息的受控澄清提问。
- [ ] 第二轮澄清必须基于新增上下文并指出仍缺少的信息，不得原样重复第一轮。
- [ ] 访客在任一澄清后补足信息时，系统结合近期上下文重新分析并继续事实处理，无需重复完整问题。
- [ ] 同一连续事实诉求完成两轮澄清后仍不完整时形成人工接续，并展示已配置的人工联系入口。
- [ ] 澄清提问和人工接续都不附引用、不接受质量反馈、不创建待解决问题，也不计入可靠拒答。
- [ ] 一个不含待澄清事实诉求的新意图会结束上一意图的澄清计数。
- [ ] 访客端、管理员预览和会话复盘能够区分两轮澄清、人工接续、可靠拒答与技术故障。
