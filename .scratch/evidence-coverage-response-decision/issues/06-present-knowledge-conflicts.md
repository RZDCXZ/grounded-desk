# 06 — 识别并呈现知识冲突

**What to build:** 当不同内容单元对同一事实诉求给出无法同时成立的依据时，助手明确展示知识冲突和冲突双方来源，让访客与管理员看到真实问题，而不是任选结论或可靠拒答。

**Blocked by:** 04 — 用证据覆盖决定单项回答或可靠拒答.

**Status:** resolved

- [ ] 覆盖判定器只有在相同适用范围内存在至少两项可验证且互不相容的证据时才能返回知识冲突。
- [ ] 纯知识冲突消息显示受控冲突说明和双方逐项引用，不生成未经证据支持的最终结论。
- [ ] 冲突证据片段与判定说明作为最小证据快照保存，并在来源更新或删除后继续随会话复现。
- [ ] 每项知识冲突自动创建独立待解决问题，且不接受普通回答质量反馈。
- [ ] 适用时间、产品、地区或条件不同但可以同时成立的内容不会被误判为知识冲突。
- [ ] 公开助手、管理员预览、会话列表、会话详情和待解决问题能够正确呈现知识冲突语义。
- [ ] 测试覆盖冲突漏检、冲突误报、伪造冲突引用、技术故障和组织隔离。
