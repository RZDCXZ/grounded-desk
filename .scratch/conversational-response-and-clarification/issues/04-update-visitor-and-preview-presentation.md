# 04 — 更新访客端与预览端呈现

**What to build:** 访客和管理员预览可以把交流性回应与澄清提问看作普通助手消息，同时保留可靠拒答的警示语义。

**Blocked by:** 02 — 路由交流性回应并使用受控模板; 03 — 对残缺问题最多澄清一次.

**Status:** ready-for-agent

- [ ] 扩展流式响应协议，使客户端能够识别交流性回应和澄清提问的最终结果。
- [ ] 两种新结果使用普通助手消息气泡，不使用可靠拒答的橙色警示卡。
- [ ] 两种新结果不显示引用、人工联系入口、质量反馈按钮或内部结果类型标签。
- [ ] 可靠拒答继续显示现有警示样式和人工联系入口。
- [ ] 有据回答继续在完成后显示服务端引用和质量反馈入口。
- [ ] 中文、英文和混合语言的模板呈现与现有语言规则一致。
- [ ] 管理员预览和公开助手保持相同结果文案、状态与视觉语义。
- [ ] 遵循现有设计系统的消息气泡、颜色、排版、间距、焦点和响应式规则。
- [ ] 端到端测试通过角色、可访问名称和用户可见文案验证行为，不依赖内部 DOM 或 CSS 类。
