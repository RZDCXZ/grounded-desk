# 05 — 在后台复盘新会话结果

**What to build:** 管理员可以在会话列表和详情中识别并筛选交流性回应与澄清提问，而现有统计和待解决问题语义保持不变。

**Blocked by:** 01 — 扩展会话结果与成本契约.

**Status:** ready-for-agent

- [ ] 会话列表识别两种新结果并显示“交流性回应”和“澄清提问”标签。
- [ ] 会话列表提供两个对应筛选项。
- [ ] 会话详情为两种新结果显示独立且可读的状态，不将其标为有据回答或可靠拒答。
- [ ] 新类型不计入有据回答、可靠拒答或技术故障统计。
- [ ] 概览页不新增交流性回应或澄清提问指标。
- [ ] 新类型不会在待解决问题页面产生条目或错误关联。
- [ ] 会话删除、筛选计数和最近结果查询继续覆盖所有合法消息类型。
- [ ] 使用公开会话产生的真实数据完成后台端到端验证，不另建只服务测试的业务入口。
- [ ] 后台页面遵循现有设计系统和对应设计稿，不引入新的视觉风格。
