# 07 — 在后台预览有据回答

**What to build:** 管理员可以在助手后台提出一个有知识依据的问题，看到流式有据回答，并在回答结束后核查由服务端生成的引用。

**Blocked by:** 02 — 导入并启用手工知识来源; 06 — 配置助手业务形象.

**Status:** ready-for-agent

- [ ] 预览问题会经过问题向量化、组织内可用内容单元召回、重排和回答生成的完整链路。
- [ ] 有充分证据的问题以流式正文返回，事实内容不超出最终证据集。
- [ ] 回答完成后展示不超过三个按知识来源去重的引用，包含保存的标题和可用原始 URL。
- [ ] 引用只由服务端最终证据集生成，模型文本中的任意 URL 不会成为可信引用。
- [ ] 每次供应商调用记录供应商、模型、Token、耗时、结果、错误类型和追踪 ID，但不记录完整提示词或回答正文。
- [ ] 使用固定向量、重排结果和模型响应的确定性测试可验证召回过滤、生成、流式结束和引用行为。
