# 08 — 预览可靠拒答与技术故障

**What to build:** 管理员能够清楚验证知识不足会产生可靠拒答，而供应商或系统故障会产生可重试的暂时不可用结果，两类结果不会相互混淆。

**Blocked by:** 07 — 在后台预览有据回答.

**Status:** resolved

- [ ] 最终证据未达到相关性门槛时，不调用模型补全业务事实，而是返回明确的可靠拒答和已配置的人工联系入口。
- [ ] Embedding、Rerank 或回答生成发生超时、限流或无效响应时，界面显示服务暂时不可用而不是可靠拒答。
- [ ] 供应商限流最多进行一次短暂退避重试，不会静默绕过重排或自动切换供应商。
- [ ] 技术故障保留管理员的问题并允许重新尝试，成功重试不会产生重复回答记录。
- [ ] 回答正文只渲染受控 Markdown，原始 HTML、脚本、iframe、图片和危险链接不会执行或显示。
- [ ] 确定性测试覆盖门槛上下、超时、限流、无效响应、一次重试以及可靠拒答与技术故障的区分。
