# 09 — 建立检索离线评测与阈值基线

**What to build:** 开发者可以用一组可重复的代表性问题评估有据回答和可靠拒答，从整组结果确定首版召回、重排和相关性阈值。

**Blocked by:** 08 — 预览可靠拒答与技术故障.

**Status:** resolved

- [x] 离线评测集至少包含十个应当获得有据回答的问题和十个应当可靠拒答的问题。
- [x] 每个可回答问题标注一个或多个预期知识来源，并检查最终引用是否来自预期来源。
- [x] 评测检查错误拒答、错误回答、来源外事实和引用缺失，而不只检查模型是否生成文本。
- [x] 评测包含少量英文问题，并验证中文、英文使用相同的证据和拒答契约。
- [x] 召回数量、重排保留数量和相关性阈值保存在服务端配置中，调整依据是整组评测结果而非单题例外。
- [x] 离线评测可通过独立命令运行，并输出足以比较配置变化的摘要结果。

## Answer

新增固定的 20 题中英文检索评测集与 `pnpm eval:retrieval` 独立命令。命令复用生产有据回答流程和服务端检索配置，汇总错误拒答、错误回答、来源外事实、引用与语言契约问题；相邻参数 `19/4/0.49` 或 `0.51` 会使整组评测失败，从而把首版 `20/5/0.5` 固定为可比较的阈值基线。
