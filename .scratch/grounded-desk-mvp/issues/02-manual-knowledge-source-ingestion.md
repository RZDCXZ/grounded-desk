# 02 — 导入并启用手工知识来源

**What to build:** 管理员可以提交一项手工知识来源，观察它从处理中变为可用，并获得已经形成知识版本、内容单元和向量的可检索知识。

**Blocked by:** 01 — 建立可重建的管理员入口.

**Status:** ready-for-agent

- [ ] 管理员可以填写标题和正文，并可选择填写一个用于引用的原始 URL。
- [ ] 提交后知识来源立即显示处理中，处理完成后显示可用并更新概览中的可用知识来源数量。
- [ ] 成功处理会保留完整知识版本，将正文按标题和段落边界形成内容单元，并为内容单元生成向量。
- [ ] 正文过短、过长或无法形成有效内容单元时，界面显示安全且可理解的失败原因，不会产生部分可用的知识版本。
- [ ] 知识来源及其派生数据都归属于当前组织，其他组织成员无法读取或修改。
- [ ] 确定性测试可以在不调用真实模型供应商的情况下验证手工导入的成功与失败行为。
