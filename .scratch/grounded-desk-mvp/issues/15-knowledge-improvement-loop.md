# 15 — 完成知识改进闭环

**What to build:** 管理员可以从一个待解决问题追溯访客上下文，补充或更新知识来源，并确认新知识立即改善已发布助手的后续回答后将问题标记为已解决。

**Blocked by:** 05 — 原子更新知识来源; 13 — 收集质量反馈并生成待解决问题.

**Status:** resolved

- [x] 待解决问题详情保留原始问题、对应回答、引用和会话入口，使管理员能够理解知识缺口或负面反馈。
- [x] 管理员可以新增知识来源或更新现有知识来源来处理该问题，不需要创建独立知识库或重新选择助手知识范围。
- [x] 新知识版本成功后立即参与已发布助手的下一次检索，无需重新发布助手。
- [x] 新知识版本失败时旧版本继续服务，待解决问题仍保持待处理。
- [x] 管理员可以在验证改进后手动将问题标记为已解决，并可在已解决视图中再次查看。
- [x] 浏览器测试覆盖一次从可靠拒答、补充知识到获得有据回答并解决问题的完整闭环。
