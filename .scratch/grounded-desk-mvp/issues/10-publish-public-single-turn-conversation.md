# 10 — 发布助手并完成公开单轮咨询

**What to build:** 管理员发布助手后获得公开访问链接，访客无需账户即可发起一次咨询，并通过与后台预览相同的知识链路获得有据回答或可靠拒答。

**Blocked by:** 08 — 预览可靠拒答与技术故障.

**Status:** ready-for-agent

- [ ] 草稿助手不能通过公开入口访问，首次发布后才生成公开 ID 和可复制的公开聊天链接。
- [ ] 公开页面展示助手名称、欢迎语、AI 身份说明以及不要提交敏感个人信息的提示。
- [ ] 访客无需注册、登录、姓名、邮箱或电话即可开始匿名会话并提交问题。
- [ ] 单轮问题会返回流式有据回答及引用，或返回可靠拒答及人工联系入口。
- [ ] 公开接口先验证助手已发布，再由助手推导组织；客户端不能通过提交组织 ID 改变数据边界。
- [ ] 管理员下线助手后，公开页面与接口停止接受新消息，但后台配置和历史数据仍然保留。
