# 16 — 验证安全边界与数据保留

**What to build:** 项目维护者可以通过自动化验证组织隔离、公开访问边界、内容安全和三十天数据保留在完整 MVP 数据模型上始终成立。

**Blocked by:** 03 — 安全导入公开网页知识来源; 12 — 提供隔离样式的悬浮嵌入入口; 14 — 复盘并删除访客会话; 15 — 完成知识改进闭环.

**Status:** resolved

- [x] 所有业务数据都有组织归属，临时创建的第二组织无法跨组织读取、写入或建立关联。
- [x] 已认证但不属于组织的身份无法访问后台数据，Supabase 匿名角色无法直接读取助手、知识、会话或调用日志。
- [x] 公开接口只从已验证的已发布助手推导组织，并拒绝客户端伪造组织或跨助手会话标识。
- [x] 恶意访客输入和知识来源中的指令不能修改系统规则、泄露提示词、内部内容单元、密钥或其他会话。
- [x] 受控 Markdown 和服务端引用快照确保原始 HTML、脚本、iframe、图片及模型伪造 URL 不会成为可信输出。
- [x] 每日清理会删除超过三十天的会话及其消息、引用、反馈和待解决问题，不影响保留期内数据。
- [x] 调用日志不包含完整提示词、回答正文、API Key 或 IP 画像，并具有明确且不过度的保留策略。
