# 04 — 管理知识来源生命周期

**What to build:** 管理员可以修复临时失败、控制知识来源是否启用，并在明确理解影响后永久删除不再需要的知识来源。

**Blocked by:** 03 — 安全导入公开网页知识来源.

**Status:** ready-for-agent

- [ ] 处理失败的知识来源显示具体失败原因，并可使用已经保存的输入重试，无需重新填写全部内容。
- [ ] 管理员停用知识来源后，它立即不再属于可用知识；重新启用后恢复当前可用知识版本。
- [ ] 停用和重新启用不会重新抓取、重新切分或丢失现有知识版本。
- [ ] 删除操作展示二次确认，并明确正文、知识版本、内容单元和向量不可恢复。
- [ ] 确认删除后该知识来源及其派生知识被移除，取消确认则不产生任何变更。
- [ ] 列表和概览状态在重试、停用、启用与删除后保持一致。
