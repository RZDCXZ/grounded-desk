# 05 — 原子更新知识来源

**What to build:** 管理员更新手工或网页知识来源时，现有知识持续可用；只有完整处理成功的新知识版本才会整体替换旧版本。

**Blocked by:** 03 — 安全导入公开网页知识来源.

**Status:** ready-for-agent

- [ ] 管理员可以修改手工内容或重新处理网页来源，并看到新知识版本的独立处理状态。
- [ ] 新知识版本处于抓取、提取、形成内容单元或向量化阶段时，旧知识版本仍然是唯一可用版本。
- [ ] 新知识版本全部成功后一次性成为当前可用版本，不会出现新旧内容单元混用。
- [ ] 新知识版本处理失败时保留失败原因，旧知识版本继续可用且无需恢复操作。
- [ ] 并发或重复更新不会让同一知识来源同时出现多个可用知识版本。
- [ ] 数据库集成测试证明成功切换、失败保留和唯一当前版本约束。
