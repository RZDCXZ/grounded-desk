# 03 — 安全导入公开网页知识来源

**What to build:** 管理员可以提交单个公开网页 URL，系统在严格网络边界内提取页面标题和主要正文，并通过与手工内容一致的处理链路使知识来源可用。

**Blocked by:** 02 — 导入并启用手工知识来源.

**Status:** resolved

- [x] 公开 HTTP 或 HTTPS HTML 页面可以被导入，页面标题和主要正文会被保留，导航、脚本、样式、表单和页脚噪声会被移除。
- [x] 本机、私网、保留地址、云元数据地址以及解析到这些地址的主机都会在抓取前或重定向时被拒绝。
- [x] 抓取限制重定向次数、响应时间、响应体积和内容类型，并为每类拒绝或失败给出可理解的处理结果。
- [x] 系统不执行页面 JavaScript，也不尝试绕过登录、验证码、付费墙或反爬限制。
- [x] 显式允许私有来源的开关只在开发环境生效；生产环境即使设置该开关也仍然拒绝私有地址。
- [x] 固定 HTML 和受控网络响应测试覆盖正文提取、DNS 变化、重定向、非 HTML、超时和超大响应。
