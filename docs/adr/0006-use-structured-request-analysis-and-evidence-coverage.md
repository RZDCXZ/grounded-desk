# 使用结构化请求分析与证据覆盖决定回答结果

ADR-0005 已经区分非事实交流与有据回答，但首版依赖固定表达集合、正则、澄清主题白名单和统一重排阈值，无法稳定处理自然改写、复合问题、部分支持与知识冲突。GroundedDesk 改为使用版本化的结构化请求分析器拆分最多三项事实诉求，再分别检索，并由独立的证据覆盖判定器依据可验证原文片段判断支持、无支持或冲突；重排分数只用于候选排序和降噪，只有完整事实诉求全部没有证据覆盖时才形成可靠拒答。

这一选择会增加模型调用、延迟、结构化持久化和评测成本，交流性回应也不再保证在 AI 预算耗尽后可用；相应地，系统能够形成部分有据回答、逐项引用和知识冲突结果，把分析失败保留为技术故障，并让管理员复现每项判断。可靠性策略继续由系统统一版本管理，不向管理员开放提示词或判定阈值，行为切换必须通过版本化决策评测集。
